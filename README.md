# Web Tabanlı Öğrenci Bilgi Sistemi (OBS)

HTML, CSS ve JavaScript kullanılarak geliştirilmiş web tabanlı Öğrenci Bilgi Sistemi projesidir.

## Özellikler

- Öğrenci kayıt sistemi
- Öğretmen kayıt sistemi
- Öğrenci giriş sistemi
- Öğretmen giriş sistemi
- Admin paneli
- Ders yönetimi
- Vize ve final notu girişi
- Öğrenci not görüntüleme
- AGNO hesaplama
- Öğrenci ve öğretmen hesaplarını dondurma
- Kayıt silme
- LocalStorage ile veri saklama

## Kullanılan Teknolojiler

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Proje

Bu proje eğitim ve geliştirme amacıyla hazırlanmıştır.
